We run @letsbuildsimply, a new Instagram account making "How a X becomes a Y" reels in Blender (3D cutaway, vertical, ~90 s). We studied two viral references:

- "How a wooden plank becomes a bridge": plank snaps → beams → flood carries it off → abutments → wider river sags → trusses → cars/trucks → steel+concrete deck → heat buckling → expansion joints ("that bump when you drive onto a bridge") → scour → deep piles → "Congratulations, you've built a bridge. You started with one plank… now you've spent $6,000,000."
- "How a hole in your yard becomes a nuclear bunker": hole caves in → steel pipe under 3 ft dirt → fallout → every 3.5 in of dirt halves radiation → straight-line rays down the doorway → bend tunnel twice → stale air → air pipe + filter + hand-crank fan → shockwave down the pipe → blast valve → door hit "like a truck" → opens outward → rubble traps you → escape hatch → can't see radiation → Geiger counter → myth: you only need 2 weeks → "Congratulations, you have built a nuclear bunker."

What makes them work:
- Second 1: the dumbest naive version, framed as "congratulations, you've built a X". It fails by second 6.
- 6–8 "But [problem] → So [fix]" loops, ~11–15 s each. Each fix causes or exposes the next problem.
- Plain-English mechanism first, then the name ("This is a blast valve."). 3–5 real technical terms.
- Every failure is a big, funny, physical, visible event (snap, flood, collapse, truck crash).
- Invisible forces shown as color-coded particles/arrows.
- One everyday "aha" that viewers have noticed in real life but never understood.
- Concrete numbers, ending with a scope-creep payoff that calls back to the opening line.
- One fixed cutaway camera on a single growing build, with only a few zooms.

Our rules:
- NO mascot and no recurring named character. Generic background people or "you" are fine.
- NOT a refrigerator (we already did one).
- The build must work as one cutaway diorama in Blender that grows step by step: one location, 6–8 add-on parts, and visible failures we can animate with simple rigid bodies, particles and shape keys.
- Everything must be factually correct. The account voice is curious and simple, with light humor.
