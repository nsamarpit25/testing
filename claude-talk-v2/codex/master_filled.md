3. 10 desired outcomes
4. 10 repeated questions
5. 10 common mistakes
6. 10 objections or limiting beliefs
7. Emotional reasons behind these problems
8. Likely phrases/language the audience uses

Score the strongest problems from 1–10 on:
- Frequency
- Emotional intensity
- Niche relevance
- Content potential
- Ease of explaining in a short reel

Select the SINGLE strongest problem for this reel and briefly explain why.

IMPORTANT: Do not invent statistics, survey results, testimonials, or factual claims. If you lack external research,
label conclusions as hypotheses/inferences.

========================
PHASE 2 — CONTENT ANGLE
========================

Create:
A. Core Problem
B. Core Insight
C. New Belief

========================
PHASE 3 — HOOK CREATION
========================

Create BOTH:

1. VERBAL HOOK
Give 10 options. Each must be immediate, specific, natural to say, curiosity-driven or problem-focused. No “Hey
guys,” unnecessary introductions, or generic openings.

2. TEXT HOOK
Give 10 short on-screen hook options. They must be easy to read quickly and should complement the verbal hook
rather than merely duplicate it.

Then select the BEST verbal hook, BEST text hook, and BEST combination. Explain the choice in one short
sentence.

========================
PHASE 4 — FINAL SCRIPT
========================

Write the final reel using exactly:

HOOK
→ Grab attention immediately.

VALUE
→ Explain the problem, mistake, misconception, or insight.
→ Make the viewer feel understood.
→ Give useful information, not filler.

SOLUTION
→ Give a clear, actionable solution.
→ Use steps/framework/examples when appropriate.

CTA
→ Give ONE clear next action.
→ Match the selected reel goal.
→ If the goal is followers, give a compelling reason to follow.
→ If comments, ask an easy but meaningful question.
→ If saves, make it worth revisiting.
→ If shares, identify who should receive it.
→ If leads/sales, create a natural next step without sounding desperate.

Write exactly as I would speak it. Use conversational language, short sentences, and no article-like or
corporate/AI phrasing.

Also provide:
- Estimated speaking time
- Approximate word count
- Pause points
- Words/phrases to emphasize

========================
PHASE 5 — RETENTION ENGINEERING
========================

Audit the script for:
1. First 1–3 second attention trigger
2. Curiosity/open loop
3. Reason to continue watching
4. Strongest payoff
5. Drop-off points
6. Sentences to shorten
7. Lines to remove
8. Places for pattern interrupts

Then produce a RETENTION-OPTIMIZED version.

Use curiosity gaps, specificity, contrast, unexpected insights, open loops, pattern interrupts, fast progression, and
