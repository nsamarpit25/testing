**CAPTION:**
Three hours of debugging wiped out by six words: "just clean it up real quick."

Git cannot roll you back to a working state you never committed. If an AI coding agent rewrites your uncommitted files directly, you can usually use the agent's built-in checkpoint rewind to undo its file edits, though that will not undo changes made by terminal commands.

Still, do not rely on a rescue when a two-second habit prevents the panic: commit the second the feature works, even if there are nineteen console.logs in it. Make it pretty on the next commit.
