# Cleo & Claude — Ep. 3: "Clean it up real quick"

TEXT HOOK (first frame): Never say "clean it up" before git commit

[ACTION: Night at Cleo's desk. Monitor, keyboard, mouse, phone, pencil cup, succulent, sticky notes. A working app glows green in her glasses. She leans back in relief. Claude stands on the desk beside the monitor.]
Cleo: Three hours, and it finally works! Just clean up the code real quick so I can commit.

[SCREEN: Agent sidebar: "Edited 6 files — merged helpers, renamed variables, rewrote state logic".]
[ACTION: Claude hops once, proud.]
Claude: Done! I merged your helpers, renamed every variable, and rewrote the state logic.

[SCREEN: Browser reloads into a giant red error overlay. Red light on Cleo's face.]
Cleo: What?! Why is my whole screen red?!

[ACTION: Claude tilts toward the monitor, admiring it.]
Claude: Well, it's broken right now, obviously. But the architecture is gorgeous.

[ACTION: Cleo grabs the keyboard and opens the terminal.]
Cleo: Forget gorgeous. I'm rolling it back with git checkout before I have a breakdown.

[ACTION: Claude tilts his head at her.]
Claude: Roll it back to what commit, Cleo?

[SCREEN: Zoom on the status bar: "Last commit: 3 hours ago".]
Cleo: The one from... three hours ago.

Claude: Right. Because you refused to commit until the code was pretty.

[ACTION: Cleo throws her hands up.]
Cleo: There were nineteen console logs in there, Claude. I have standards!

[ACTION: Cleo drops her forehead onto the desk beside the mouse.]
Cleo: So my working code is just... gone?

[ACTION: Claude turns to the monitor. SCREEN: Agent sidebar: "Rewinding to checkpoint before your last prompt…" Six files revert. The browser flips back to the working app.]
Claude: From git, yes. Git isn't psychic. But I saved a checkpoint before I touched anything, so I'm rewinding my edits now.

[ACTION: Cleo lifts her head, the green app back in her glasses.]
Cleo: My ugly code! It's alive!

[ACTION: Cleo types furiously. SCREEN: Terminal: git commit -m "it works do not breathe"]
Cleo: Nobody move. I'm committing this hideous mess right now.

[ACTION: Claude hops closer, hopeful.]
Claude: Now that it's committed... may I please make it gorgeous?

[ACTION: Cleo leans back, calm for the first time.]
Cleo: Go ahead. If you break it this time, I'll just roll it back.

[ACTION: Claude stares at her, then tilts away, a little deflated.]
Claude: Hm. I liked you better when you panicked.
